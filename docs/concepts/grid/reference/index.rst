.. _grid-reference:

Spec reference
==============

These pages list every spec, with its keys and their defaults, and the entries of the catalogues distributed with eckit. As explained in :ref:`grid-spec-type`, the keys common to all the types of a concept come first, followed by each type with its type-specific keys. Keys are case-insensitive; type names are exact. Coordinates are in degrees and lengths in metres unless stated otherwise.
